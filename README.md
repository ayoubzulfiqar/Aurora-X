# Aurora X — Zed Theme

A pure-AMOLED dark theme with blue/purple aurora tones, for Zed. True-black
`#000000` background, aurora accent ramp, and full syntax + UI coverage following
the official Zed theme schema (v0.2.0).

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## Features
- Pure-black `#000000` background (editor + UI), OLED-friendly.
- Aurora accents: `#86A5FF` ice, `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- 141 style keys, 122 syntax keys, 8 players, 10 accents (schema v0.2.0 valid).
- Terminal ANSI palette, git/diagnostic/UI theming.

## Install
1. Download `aurora-x-zed-3.0.0.tar.gz` from the Releases page (tag `zed-v3.0.0`).
2. Extract so you have `themes/aurora-x.json` (plus `extension.toml`, `LICENSE`, `README.md`).
3. Copy `themes/aurora-x.json` into `~/.config/zed/themes/` (or your config `themes/` dir).
4. `cmd-k cmd-t` (or `ctrl-k ctrl-t`) → select **Aurora X**.

## Configure
Add to `settings.json` for per-surface overrides, e.g.:
```json
{ "theme": "Aurora X", "theme_overrides": { "editor.background": "#000000" } }
```

## Verify
`cmd-k cmd-t` shows *Aurora X*; editor background is `#000000`.
Theme generated by `build_zed_theme.py`, validated against `zed.dev/schema/themes/v0.2.0.json`.
