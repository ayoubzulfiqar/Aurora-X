# Aurora X — VS Code Theme

A pure-AMOLED dark theme with blue/purple aurora tones. True-black `#000000`
background, aurora accent ramp, and full UI + syntax coverage.

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## Features
- Pure-black `#000000` background (editor + UI), OLED-friendly.
- Aurora accents: `#86A5FF` ice, `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- 461 UI color keys + 86 TextMate token rules for deep syntax coverage.
- Terminal ANSI palette, bracket-pair colors, minimap, breadcrumbs, peek/quick-input theming.

## Install
1. Download `aurora-x-3.0.0.vsix` from the Releases page (tag `vscode-v3.0.0`).
2. VS Code → Extensions → `...` → **Install from VSIX** → select the file.
3. Reload, then **Preferences: Color Theme** → `Aurora X`.

## Verify
`Preferences: Color Theme` lists *Aurora X*; editor background is `#000000`.
Theme generated by `build_vscode_theme.py` (strict JSON, validated).
