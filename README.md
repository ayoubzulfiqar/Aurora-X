# Aurora X

A pure-AMOLED dark theme with blue/purple aurora tones — ported to five editors, each
maintained as its own independent repository.

> This repository is an **index/hub only**. Each editor port lives in its own repo
> (separate entity, no cross-branch compare/pull-request banners).

## Editor ports

| Editor | Repository | Install |
| --- | --- | --- |
| Visual Studio Code | [Aurora-X-VSCode](https://github.com/ayoubzulfiqar/Aurora-X-VSCode) | Install from VSIX / Marketplace |
| Zed | [Aurora-X-Zed](https://github.com/ayoubzulfiqar/Aurora-X-Zed) | Copy `themes/aurora-x.json` to `~/.config/zed/themes/` |
| Android Studio / IntelliJ | [Aurora-X-Android-Studio](https://github.com/ayoubzulfiqar/Aurora-X-Android-Studio) | Install from Disk (zip) / import `.icls` |
| Neovim | [Aurora-X-Neovim](https://github.com/ayoubzulfiqar/Aurora-X-Neovim) | Plugin manager or extract tarball to `~/.config/nvim/` |
| Visual Studio 2026 | [Aurora-X-Visual-Studio](https://github.com/ayoubzulfiqar/Aurora-X-Visual-Studio) | Extensions → Theme → Import `.vstheme` |

Every port shares the same palette:

- True-black `#000000` AMOLED background
- Aurora accents: `#86A5FF` ice, `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold
