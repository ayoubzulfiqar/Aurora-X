# Aurora X — Visual Studio 2026 Theme

A pure-AMOLED dark theme with blue/purple aurora tones, ported to Visual Studio 2026
(18.7+). Uses the modern Fluent semantic token system (`Shell` + `ShellInternal` categories)
with `FallbackId` set to the built-in Dark theme, so every surface that isn't explicitly
recolored inherits the correct Dark values automatically.

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## What it does
- True-black `#000000` shell + editor background (pure AMOLED).
- Aurora accents: `#86A5FF` ice (accent), `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- 493 color tokens: 75 Fluent `Shell` semantic tokens, 21 `ShellInternal` chrome tokens,
  plus a classic `Environment` category (397 tokens) for the VS Color Theme Editor / older tooling.
- Falls back to the Dark theme for any token not overridden → guaranteed consistent, accessible UI.

## Install
1. Download `Aurora X.vstheme` from the
   [Releases](https://github.com/ayoubzulfiqar/Aurora-X/releases) page (tag `visualstudio-v3.0.0`).
2. Visual Studio 2026 → **Extensions** → **Theme** (or **Tools → Options → Environment → Visual Experience → Theme colors**).
3. Import the `.vstheme`, then select **Aurora X** as the theme.
   - Alternatively: place `Aurora X.vstheme` in
     `%LOCALAPPDATA%\Microsoft\VisualStudio\18.0_xxxxxxxx\ColorThemes\` and restart.

> Note: VS 2026 reads the new `Shell`/`ShellInternal` tokens first and falls back to the Dark
> theme, so the theme is fully functional without enumerating all ~1,800 legacy tokens.

## Validate
The `.vstheme` is well-formed XML: `Theme` carries `FallbackId="{1ded0138-47ce-435e-84ef-9ec1f439b749}"`,
the `Shell`/`ShellInternal` categories use the exact Microsoft GUIDs, and every `Source` is an
8-digit `AARRGGBB` value. Generated by `build_vs2026_theme.py`.
