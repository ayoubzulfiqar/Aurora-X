# Aurora X — Visual Studio 2026 Theme

A pure-AMOLED dark theme with blue/purple aurora tones, for Visual Studio 2026
(18.7+). Uses the modern Fluent semantic token system (`Shell` + `ShellInternal`
categories) with `FallbackId` set to the built-in Dark theme.

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## Features
- True-black `#000000` shell + editor background (pure AMOLED).
- Aurora accents: `#86A5FF` ice (accent), `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- 493 color tokens: 75 Fluent `Shell` semantic tokens, 21 `ShellInternal` chrome tokens, plus a classic `Environment` category (397 tokens).
- Falls back to the Dark theme for any token not overridden → consistent, accessible UI.

## Install
1. Download `Aurora X.vstheme` from the Releases page (tag `visualstudio-v3.0.0`).
2. Visual Studio 2026 → **Extensions → Theme** (or **Tools → Options → Environment → Visual Experience → Theme colors**).
3. Import the `.vstheme`, then select **Aurora X**.
   - Or place `Aurora X.vstheme` in `%LOCALAPPDATA%\Microsoft\VisualStudio\18.0_xxxxxxxx\ColorThemes\` and restart.

## Verify
The `.vstheme` is well-formed XML: `Theme` carries `FallbackId="{1ded0138-47ce-435e-84ef-9ec1f439b749}"`,
`Shell`/`ShellInternal` use exact Microsoft GUIDs, every `Source` is 8-digit `AARRGGBB`.
