# Aurora X — Neovim Colorscheme

A pure-AMOLED dark theme with blue/purple aurora tones, for Neovim. True-black
`#000000` background, aurora accent ramp, and full coverage for editor chrome,
TreeSitter captures, LSP semantic tokens, diagnostics, and popular plugins.

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## Features
- Pure-black `#000000` background (editor + UI), OLED-friendly.
- Aurora accents: `#86A5FF` ice, `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- 424 highlight groups: 67 editor, 44 legacy syntax, 118 TreeSitter `@`, 57 LSP/diagnostic, 138 plugin.
- Plugin support: treesitter-context, gitsigns, telescope, nvim-tree, neo-tree, which-key, cmp, indent-blankline, lualine, notify, diffview, markdown, bufferline, noice, mini.nvim, hop/leap.
- Full 16-color terminal ANSI ramp.

## Install (plugin manager)
With `lazy.nvim`:
```lua
{
  "ayoubzulfiqar/Aurora-X",
  branch = "neovim",
  lazy = false,
  priority = 1000,
  config = function()
    require("aurora-x").setup()
    vim.cmd.colorscheme("aurora-x")
  end,
}
```

## Install (manual)
1. Download `aurora-x.nvim.tar.gz` from the Releases page (tag `neovim-v3.0.0`).
2. Extract into `~/.config/nvim/` (so you get `lua/aurora-x/` and `colors/aurora-x.lua`).
3. `:colorscheme aurora-x`

## Configure
```lua
require("aurora-x").setup({ -- transparent = true, -- italics = false, })
```

## Verify
`:colorscheme aurora-x`, then `:highlight Normal` — `guibg=#000000`.
Files generated by `build_nvim_theme.py` and structure-checked (brace balance + `@` groups).
