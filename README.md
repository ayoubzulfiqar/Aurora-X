# Aurora X — Android Studio / IntelliJ Theme

A pure-AMOLED dark theme with blue/purple aurora tones, for Android Studio and
other IntelliJ-platform IDEs. True-black `#000000` background, aurora accent ramp.

Author: **Ayoub Zulfiqar** — https://ayoubzulfiqar.com · contact@ayoubzulfiqar.com

## Features
- Pure-black `#000000` editor background, AMOLED-friendly.
- Aurora accents: `#86A5FF` ice, `#C792EA` nebula, `#89DDFF` cyan, `#C3E88D` green, `#F78C6C` ember, `#FFCB6B` gold.
- Editor color scheme (`Aurora X.icls`, 238 attributes) + UI theme (`Aurora X.theme.json`) + `META-INF/plugin.xml`.

## Install (plugin)
1. Download `aurora-x-android-3.0.0.zip` from the Releases page (tag `android-v3.0.0`).
2. Android Studio → **Settings → Plugins → ⚙ → Install Plugin from Disk** → select the zip.
3. Restart, then **Settings → Appearance & Behavior → Appearance → Theme** → `Aurora X`.

## Install (editor scheme only)
Import `Aurora X.icls` via **Settings → Editor → Color Scheme → ⚙ → Import Scheme**.

## Verify
Editor background is `#000000`; UI chrome uses the aurora accent ramp.
Generated by `build_android_scheme.py`; both XMLs parse cleanly.
